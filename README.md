# Velora — Clothing E-Commerce Website

Velora is a modern clothing e-commerce website built with Next.js, React, TypeScript, and CSS. It focuses on a clean, minimalist design for presenting fashion collections and creating a user-friendly browsing experience.

## Features

- Modern, minimalist fashion-focused UI
- Clothing collection presentation
- Built with Next.js and React
- Type-safe development using TypeScript
- Custom styling with CSS

## Tech Stack

- **Framework:** Next.js
- **Frontend Library:** React
- **Language:** TypeScript
- **Styling:** CSS
- **Package Manager:** npm
- **Version Control:** Git and GitHub

## Getting Started

Follow these steps to run Velora locally on your computer.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) — preferably an active LTS version
- npm, which is included with Node.js
- [Git](https://git-scm.com/)

Check your installations:

```bash
node -v
npm -v
git --version
```

### 1. Clone the Repository

```bash
git clone https://github.com/123pratham/ecom-website.git
```

### 2. Navigate to the Project Directory

```bash
cd ecom-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Website

Open your browser and visit:

http://localhost:3000

The development server automatically refreshes the page when you make supported code changes.

## Available Scripts
